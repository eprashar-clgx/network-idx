# The index is a composite indicator; validate by construct validity, not accuracy

The Fiber Potential Index measures a latent construct ("fiber opportunity") with **no
observed label**, so we never compute accuracy or use a held-out test set. Credibility
comes from **construct validity**: convergent evidence across four independent axes —
internal/structural robustness (sensitivity, coherence, spatial), external convergent
agreement (ACS, BEAD/RDOF funding, peer indices such as the Purdue DDI),
predictive/temporal power (does an earlier-vintage score lead future fiber/funding), and
expert/face validity (blind manual review). We record this because a reader expecting a
supervised model will look for a test set and metrics like accuracy and find none — that
absence is deliberate, and the composite-indicator framing (OECD/JRC handbook, Cronbach &
Meehl construct validity) is the governing standard for this project.
